# Caesar Cipher Encryption and Decryption Tool

## 1. Project Title
**Caesar Cipher Encryption and Decryption using Python**

## 2. Objective
To create a Python program that encrypts and decrypts text using the Caesar Cipher technique. The user can select a shift value (key) to control how many positions each alphabet moves.

## 3. Basic Features
- Accepts text from the user.
- Allows the user to select a shift key.
- Encrypts text by shifting alphabet positions.
- Decrypts encrypted text using the same key.
- Supports uppercase and lowercase letters.
- Preserves spaces and special characters.
- Displays original, encrypted, and decrypted text.

## 4. Technologies Used
- Programming Language: Python 3
- Operating System: Kali Linux / Ubuntu
- Concepts: String Operations, ASCII Values, Loops, Conditional Statements, Modulo Operator.

## 5. Installation and Execution

Install Python 3:

```bash
sudo apt update
sudo apt install python3 -y
```

Clone the repository:

```bash
git clone https://github.com/USERNAME/Caesar-Cipher-Tool.git
cd Caesar-Cipher-Tool
```

Run the program:

```bash
python3 caesar_cipher.py
```
